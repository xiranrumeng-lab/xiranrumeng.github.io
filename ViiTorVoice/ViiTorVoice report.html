01 / 能力结论

核心亮点集中在音频局部编辑与音色保持。

公开体验入口偏参考音驱动：Voice Edit 需要原音频，Voice Clone、情绪、副语言和跨语种都需要参考音。报告因此把能力拆成“编辑、克隆、控制、迁移”四层，而不是按传统 TTS 评估。

核心优势

局部编辑成立

官方中英文 demo 均达到 4.8-5.0，多处替换后基本无痕，是当前最明确的差异化能力。

稳定优势

音色保持稳定

新闻播报参考音的中性克隆拿到 5.0，跨语种失败时也常能保留音色轮廓。

需挑样例

情绪需要挑样例

开心和愤怒更可用，悲伤与害怕在年轻女声上容易变成刻板表演。

风险能力

副语言和跨语种不稳

副语言容易突兀或机械；英日韩粤跨语种发音问题明显，当前不建议生产承诺。

02 / 体验路径

体验路径从“入口可用”走到“生产边界”。

体验路径使用三条参考音色、官方 demo 和重构测试集，形成对 ViiTorVoice 能力优劣势的完整判断。

步骤 01

确认入口

公开 Space 主要提供 Voice Edit 与 Voice Clone 两个入口，未发现可选发音人库。

步骤 02

准备参考音

使用新闻播报、年轻女声口播和官方预置 demo，避免只测单一音色导致误判。

步骤 03

生成样片

覆盖局部编辑、克隆、4 类情绪、8 类副语言、组合控制和跨语种。

步骤 04

人工评分

每条按发音、自然度、音色、控制点、节奏和生产可用性评分并记录评语。

03 / 评测方法

评测方法围绕“参考音、控制点、生产可用性”展开。

同一模型在不同参考音上的表现差异很大，所以报告不只看平均分，还看哪种输入条件下更稳定。

先按参考音和任务分层，不把所有样片混在一起比较。

新闻播报更适合测中性克隆和跨语种，年轻女声更适合压测口语情绪和副语言，官方 demo 用来判断模型理想条件下的上限。

新闻播报参考音：负责稳定性和中性克隆。
年轻女声参考音：负责自然口语和轻情绪。
官方预置样例：负责能力上限对照。
同一控制点必须能听到原声与结果，避免凭印象评分。

每条样片按六个维度打分。

评分不是单纯听感分，而是拆成发音准确、自然度、音色一致、控制点、节奏连贯和生产可用六项。最后再归类为“优势能力、可挑样例能力、风险能力”。

发音准确：是否错读、漏读、不可理解。
控制点：编辑、情绪、副语言或跨语种是否真的生效。
生产可用：是否能进入真实流程，而不是只做 demo。
评语记录：所有明显问题直接写在样本旁边。

用“优势能力”和“风险能力”分开表达。

局部编辑和音色克隆属于优势能力；情绪控制属于可挑样例能力；副语言和跨语种应归为风险能力，避免在生产场景中直接承诺。

优势能力：局部编辑、新闻播报中性克隆。
可挑样例：开心、愤怒、清嗓子、部分笑声。
风险区：咳嗽、叹气、呼吸、惊讶、倒吸气。
暂不承诺：日韩粤跨语种生产可用。

最佳信号

新闻音色中性克隆：参考音保持最稳

这条拿到 5.0，说明模型在清晰、稳定、中性播报参考音上具备较强克隆能力。它也是后续局部编辑和跨语种判断的音色基准。

控制点新闻播报参考音色 → 纪录片长句。重点听播报腔、音色厚度、长句停顿和断句是否自然。
生成文本在漫长的历史长河中，人类从未停止对未知世界的探索，从古老的丝绸之路到现代的太空站，每一次突破都凝聚着无数人的智慧与勇气。
均分 5.0 优势样本
核心能力

官方中文局部编辑

多处替换后基本无痕，证明官方 demo 条件下局部编辑能力成立。

修改点他人 → 自己；冲动 → 他人；父亲 → 灵魂。重点听多处替换后，气口、语速和语义重音是否仍然自然。
原文当你明白如何为他人考虑，如何不再被冲动控制头脑，你的父亲应该就已经满足了。
改文当你明白如何为自己考虑，如何不再被他人控制头脑，你的灵魂应该就已经满足了。

悲伤情绪 / 女声口播

评语指出“没有明显悲伤，拖音较多，感情刻板不自然”。年轻女声情绪控制不如新闻音色稳定。

控制点句首加入悲伤情绪标记，告别文本。重点听女声是否有低落感、语速放缓和情绪停顿。

风险样例

惊讶：副语言割裂感明显

副语言可以被触发，但常不像“同一个人自然发出”。这条评语为“惊讶突兀，不融合，有割裂感”。

控制点惊讶 oh 位于“等等，”之后。重点听 oh 是否融入中文语流，是否像自然惊讶反应。
生成文本等等，<|nv-Surprise-oh|>这个版本好像真的解决了之前的问题。
均分 3.7暂不适合生产
语言风险

粤语跨语种：音色像，但语言不可用

音色和节奏保留较好，但粤语未生效，内容不可理解。这说明跨语种短板主要在目标语言发音，而不是音色保持。

控制点中文新闻参考音色 → 粤语生成。重点听粤语声调、口音和原音色保留。
生成文本今日我哋测试一下语音编辑同埋声音复制嘅效果。
均分 2.7暂不适合生产
05 / 风险边界

边界记录决定它能否进入生产流程。

样本覆盖已经足够支撑完整能力判断；更重要的是把能力边界说清楚，避免把优势能力和风险能力混在一起表达。

主要风险

问题集中在“表演自然度”和“目标语言发音”，不是简单参数调节就能完全解决。

副语言衔接副语言插入后容易与前后语流割裂，咳嗽、叹气、呼吸、惊讶和倒吸气都出现过突兀感。
情绪表演年轻女声的悲伤、害怕表现偏刻板，容易像话剧式表演，不像自然口语情绪。
跨语种发音英文有中式口音，日文、韩文机械，粤语内容不可理解，跨语种不宜用于正式生产。
官方样例条件局部编辑高分主要来自官方 demo 条件，自有素材仍需在真实错词、产品名、数字替换场景验证。
参考音依赖公开入口未见可选发音人库，所有生成基本依赖参考音或原音频，产品化使用需要稳定素材准备流程。
06 / 评分汇总

按评分维度汇总本次体验结论。

整体均分 3.94，说明它不是“不能用”，而是能力层级分化明显：编辑和音色保持强，生产可用性被副语言和跨语种拖低。

发音准确4.38中文整体较稳，外语和粤语明显拉低。
音色一致4.32参考音色保留能力较好，是当前优势。
自然度3.94普通克隆较自然，副语言和情绪表演拉低。
控制点3.88局部编辑和部分情绪有效，副语言位置与质感不稳。
节奏连贯3.88中性播报较好，副语言插入处容易断裂。

07 / 最终判断

能力结论已经清晰：强在编辑，弱在表演和跨语种。

ViiTorVoice 更适合被定位为“以局部编辑和音色克隆为核心的可编辑语音模型”。它可以支撑编辑修音和音色复用场景，但不适合直接承诺副语言、复杂情绪和多语种生产可用。

优势

优势能力

局部编辑、新闻播报中性克隆、官方中英文编辑 demo。这些样本能直接证明技术亮点。

谨慎使用

挑样例能力

开心、愤怒、清嗓子、部分笑声可以展示，但必须先人工筛选，不适合批量放开。

不宜承诺

风险能力

副语言自然度、悲伤/害怕女声口语、日韩粤跨语种暂不建议进入生产承诺。
