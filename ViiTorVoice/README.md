# ViiTorVoice 报告 GitHub 上传包

这个目录可以直接作为 GitHub Pages 仓库根目录上传。

## 目录结构

```text
index.html
promo-banner.png
audio/01_参考原声-新闻播报.mp3
audio/02_生成结果-中性克隆.mp3
audio/03_原音频.mp3
audio/04_改后音频.mp3
audio/05_参考原声-女声口播.mp3
audio/06_生成结果-悲伤.mp3
audio/07_生成结果-惊讶oh.mp3
audio/08_生成结果-粤语.mp3
```

## 上传方式

上传本目录下的全部内容即可。`index.html`、`promo-banner.png` 和 `audio/` 必须保持在同一级目录。

报告中的音频都引用为 `audio/xxx`，底部 banner 引用为同级 `promo-banner.png`。
